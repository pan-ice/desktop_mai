# 独立 SDK 网关与插件反向连接

桌宠使用独立 `MessageGateway` 插件接入 MaiBot，插件拥有 SDK 消息转换与会话解析，桌宠只认识版本化的桌宠协议。旧 `maim-message` 链路依赖内核明确计划移除的兼容字段，继续使用会把上游实现变化传播到客户端。

桌宠监听本机地址，插件主动连接。MaiBot 热重载会同时预热新旧 Runner；插件自身监听固定端口会争用资源。反向连接避免此问题，同时要求远程部署使用 SSH 隧道或独立 TLS 代理。新实例握手就绪后替换旧连接；Host 切换 generation 时可能出现短暂重连，不承诺无缝切换或跨进程恰好投递一次。

消息请求以 Host 接收回执为准，出站回复以桌宠保存回执为准。断线时不自动重放状态不明的请求，以免重复进入记忆或执行工具。内核会话通过 `ctx.chat.open_session` 获取，主动陪伴调用 `ctx.maisaka.proactive.trigger`。
