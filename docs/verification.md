## 2026-10-17 Live2D 运行库复用

- 原导入流程只在各角色目录保存 Core，再导入其他模型时仍会要求选择 Core。运行库现独立保存在应用数据目录的 `models/.live2d-core/`，首次设置后自动复用；旧版角色中的 Core 在启动时自动迁移，移除角色或移动原始文件不会丢失运行库。
- 全新用户只需准备完整模型。首次导入找不到 Core 时，应用通过 Electron 的系统网络与代理从固定的 Live2D 官方 HTTPS 地址下载并保存，随后继续导入；下载请求合并，30 秒超时，按文件流执行 10 MB 上限，校验内容及 JavaScript 语法后原子保存。下载失败、错误页面、超大文件及中断均不覆盖已有运行库。
- 「角色衣橱」增加运行库状态、「下载官方运行库／更新官方运行库」、「重试下载」和「从本地导入」入口，显示下载进度与错误。更换后使用内容摘要更新资源地址，控制面板和桌宠重新创建渲染器，并等待 Core 的 WebAssembly 初始化。Cubism 2 的 `.model.json` 显示明确的不支持提示。
