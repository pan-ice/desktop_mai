2026-10-16 补验 Live2D：使用用户提供的洛天依「翡翠石」原版模型（Cubism 5.0 导出）与从 Live2D 官方地址取得的 Core 5.1.0，现有 `pixi-live2d-display/cubism4` 可实际加载，无需升级渲染依赖。控制面板、透明桌宠均有可见像素，待机、眨眼、点头、摇头动作可加载和播放。实测发现逐帧写入的睡眠闭眼参数会被待机动作覆盖，改为在 `beforeModelUpdate` 写入后，双窗口的说话口型、持续闭眼和醒来睁眼断言通过；TypeScript、生产构建与既有 22 项测试通过。此结论针对该模型和 Core 组合。

同日补验清晰度：复现角色放大后仍拉伸原有 230×240 画布的情况。Live2D 改为至少两倍采样，普通大小画布为 460×480；同时按屏幕像素密度与容器实际缩放计算渲染分辨率，监听设备像素尺寸变化。通过 Chromium 模拟 2 / 3 倍像素密度，组合 75%、100%、160% 角色大小连续切换，断言画布像素始终覆盖实际显示所需像素；3 倍屏幕、160% 角色大小时达到 1104×1152。相同实机测试中的口型、睡眠与动作检查保持通过。模型贴图未修改。

同日补验辫子惯性：「翡翠石」具有左右侧发的发根、中段、发梢六个有效参数，但没有物理配置，原先转头时六个参数峰值均为零。播放器现为完整分段侧发叠加三段弹簧惯性，按模型实际网格方向校准转头反作用，并限制幅度、稳定处理长暂停。60 FPS、25° 转头阶跃测试中，中段约晚 117 ms 达到峰值，发梢约晚 250 ms；停头后衰减回静止，六个参数均有实际网格响应且保持范围。已有原生物理的模型保留原配置，「减少动画」模式不叠加惯性。新增五项单元测试，全部 27 项通过；实际模型、双窗口、口型、睡眠及高 DPI 缩放回归通过。此优化不修改原模型或贴图。使用 `test:live2d` 的 `--hair-only` 可单独复验；增加 `--record-hair` 会在测试输出目录保存短片 `hair-dynamics.webm`。

复验命令：先运行 `npm run build`，再运行 `npm run test:live2d -- <模型入口.model3.json> <官方live2dcubismcore.min.js>`。脚本使用独立数据目录，在实际绘制前采样眼睛和口型参数，退出时关闭测试应用并删除测试数据；截图及报告保存在 `.cache/live2d-smoke/`。模型与 Core 由运行者提供，未加入源码或发行资源。

多人接入验证使用回环 WebSocket 服务。公网域名、Caddy 证书签发、Linux systemd 和实际服务器容量尚未实机验收。共享内核的全局人物画像等数据机制保持原样，本次验证的是连接、身份、私聊、回复与客户端历史归属，不代表完成租户级数据库与工具权限隔离。部署范围见 [SERVER.md](../MaiBot/plugins/desktop_pet_adapter/SERVER.md)。

桌面流程、实际协议与内核托管脚本都在退出路径中回收自己启动的应用和服务。源码部署与 Windows 解包程序共用 `test:desktop`，通过 `MAI_TEST_EXE` 指定可执行文件。NSIS 便携启动器不转发 Playwright 的 Electron 调试管道，最终便携入口使用独立 CDP 的 `test:portable`；未将直接使用 Electron 管道的超时尝试计为通过。
