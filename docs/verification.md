桌面测试没有调用在线 LLM，没有使用用户 API Key，也没有加载用户人物模型。消息端使用实际插件与官方 SDK，Host 的模型 / 会话业务由测试 Host 替代，语音端使用本地 API；音视频设备是虚拟设备，3D 是生成的 GLB。此结果不代表已验收真实模型回复、实际记忆效果或在线工具执行。Live2D 的 Core 与具体角色仍需导入后验收。

多人接入验证使用回环 WebSocket 服务。公网域名、Caddy 证书签发、Linux systemd 和实际服务器容量尚未实机验收。共享内核的全局人物画像等数据机制保持原样，本次验证的是连接、身份、私聊、回复与客户端历史归属，不代表完成租户级数据库与工具权限隔离。部署范围见 [SERVER.md](../MaiBot/plugins/desktop_pet_adapter/SERVER.md)。

桌面流程、实际协议与内核托管脚本都在退出路径中回收自己启动的应用和服务。源码部署与 Windows 解包程序共用 `test:desktop`，通过 `MAI_TEST_EXE` 指定可执行文件。NSIS 便携启动器不转发 Playwright 的 Electron 调试管道，最终便携入口使用独立 CDP 的 `test:portable`；未将直接使用 Electron 管道的超时尝试计为通过。

最终文件与 SHA256 保存在 `release/SHA256SUMS.txt`。安装与迁移步骤见 [维护指南](maintenance.md)。
